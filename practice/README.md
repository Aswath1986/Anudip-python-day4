# Simple Practice

Twenty short programs — 5 for each Day 4 topic. Each one is small enough to read in a
minute, shows its output when run, and ends with a "Try it yourself" task.

Run from inside a topic folder, for example:

```
cd practice/1_functions
python p1_area_of_rectangle.py
```

| Folder | Programs |
|--------|----------|
| `1_functions` | 1. Area of a rectangle · 2. Even or odd · 3. Greeting with a default value · 4. Largest of three · 5. Total and average |
| `2_procedures` | 1. Welcome message · 2. Multiplication table · 3. Star pattern · 4. Shopping list · 5. Function vs procedure |
| `3_try_except_finally` | 1. Divide safely · 2. Text to number · 3. List and dictionary errors · 4. else and finally · 5. Raise your own error |
| `4_file_operations` | 1. Write and read · 2. Read line by line · 3. Append to a file · 4. Count lines and words · 5. Marks file |

The file programs delete the text file they create at the end. Remove the `os.remove(...)`
line if you want to open the file and look at it.
